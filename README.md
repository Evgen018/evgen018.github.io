# evgen018.github.io

Публичный хостинг эскизов под заявки на фриланс-биржах. Форма заявки файлы не принимает,
поэтому работу прикладываем ссылкой, а ссылка должна вести на чистый домен без чужих плашек
и без предупреждений репутационных расширений.

- Адрес сайта: https://evgen018.github.io
- Страница эскиза: `https://evgen018.github.io/s/<slug>/`

## Как добавить эскиз

Из корня `AI_OS`:

```
python workflows/image-studio/publish_sketch.py <slug> <файл-картинки> [ещё файлы] \
    --title "Заголовок страницы" [--note "Подпись под картинками"]
```

Скрипт кладёт картинки в `s/<slug>/`, собирает `index.html` и печатает готовую ссылку.
После этого изменения нужно закоммитить и запушить в GitHub Desktop, страница поднимается
примерно за минуту.

Если под заказ собрана своя страница (живой SVG, анимация, текст на языке заказчика),
её отдают флагом `--page`, и тогда галерея из картинок не собирается:

```
python workflows/image-studio/publish_sketch.py <slug> \
    --page <путь к готовому index.html> [файлы картинок]
```

Публикацию делает сборка GitHub Pages, она видна во вкладке Actions репозитория. Обычно это
минута, но сборка может и застрять в очереди: 06.08.2026 три прогона простояли в статусе
`queued` больше суток, и кнопка отмены на них не действовала. Признак застревания один:
коммит в ветке есть, а на живом адресе прежняя версия. Проверять надо не время, а содержимое
живой страницы.

## Что сюда не кладём

Репозиторий публичный. Только эскизы и концепты, никаких личных данных, документов,
переписки и материалов заказчиков, на которые нет разрешения.
